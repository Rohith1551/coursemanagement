# Course Management System

A full-stack application for managing students and courses. Built with Node.js, Express, MongoDB, and a simple HTML/CSS/JavaScript frontend.

## Features

- Student CRUD operations
- Course CRUD operations
- Student search
- Dashboard statistics
- Health monitoring
- Logging with Winston and Morgan
- MongoDB integration

## Tech Stack

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Winston
- Morgan

### Frontend
- HTML
- CSS
- JavaScript
